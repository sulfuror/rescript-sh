---
title: Update
---
Check for and download the latest version of rescript directly from the GitLab master branch. 

If there is a newer version available, the script will prompt you to install it and automatically replace your current installation.

Usage:
```bash
rescript update
```

### Example Output

```text
rescript version 6.0 is available; do you want to install it? (y/n): y
Rescript have been updated to the latest version!
```
