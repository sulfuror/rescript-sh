Check for and download the latest version of rescript directly from the latest GitHub release.

If there is a newer version available, the script will prompt you to install it and automatically replace your current installation.

Usage:

```bash
rescript update
```

### Example Output

```text
rescript version 7.0.0 is available; do you want to install it? (y/n): y
Rescript has been updated to the latest version!
```
