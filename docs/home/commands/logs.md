---
title: rescript logs
---

The `logs` command allows you to view or manage the log files generated by rescript (if `LOGGING="yes"` is set in your configuration).

### Usage
```bash
rescript [repo_name] logs [options]
```

### Options
Usually requires arguments to display specific logs or manage them. It's often easier to navigate to `~/.rescript/logs/` to read the log files directly.

### Examples

**View logs for a repository:**
```bash
rescript my_repo logs
```
*(Check command `--help` for specific log querying options)*
