There are three commands that will not work as restic usually work, and those are the following commands:

1. **backup**: This command will run a backup according to the variables set before.
2. **help**: This command will display `rescript` help.
3. **version**: This command will display the current version of `rescript` you're using.
 
As far as I've tested, all other restic commands will run as using restic alone. For help
with restic commands type:

```
restic help [command]
```

Please see restic `help` and [documentation](https://restic.readthedocs.io/en/stable/) for more.

### Configuration Commands

1. **[config](commands/config)**: Launch the interactive wizard or configure a repository/global settings.
2. **[editor](commands/editor)**: Change default text editor used by rescript.
3. **[help](commands/help)**: Display rescript usage.
4. **[install](commands/install)**: Install rescript.
5. **[update](commands/update)**: Check/install new rescript version.
6. **[version](commands/version)**: Display rescript version.

### Repository Commands

1. **[all](commands/all)**: A powerful orchestrator command to execute commands sequentially or in parallel across all repositories.
2. **[automatic](commands/automatic)**: Run backup and cleanup policies sequentially.
3. **[backup](commands/backup)**: Take a snapshot using the values set in your configuration file.
4. **[cleanup](commands/cleanup)**: Perform a forget according to retention policies, followed by a prune.
5. **[diff](commands/diff)**: Automatically compare the two most recent snapshots.
6. **[env](commands/env)**: Display the exact variable values loaded from your configuration file.
7. **[extract](commands/extract)**: Extract a single file or directory from a specific snapshot with a progress bar.
8. **[history](commands/history)**: Display a detailed timeline of a specific file or folder across all snapshots.
9. **[info](commands/info)**: Display stats for the latest and all snapshots in a custom table.
10. **[init](commands/init)**: Initialize a new restic repository.
11. **[logs](commands/logs)**: Display or manage log files generated by rescript.
12. **[mounter](commands/mounter)**: Mount your repository as a virtual file system in your `/home`.
13. **[next](commands/next)**: Display next scheduled automatic cleanup time.
14. **[restorer](commands/restorer)**: Easily restore a snapshot using an interactive menu or manual ID.
15. **[search](commands/search)**: Quickly search for a specific file or directory across all your snapshots.
16. **[size](commands/size)**: Calculate the exact size of a specific snapshot ID with a progress bar.
17. **[snaps](commands/snaps)**: Wrapper around `restic snapshots --compact` to list all snapshots cleanly.
18. **[status](commands/status)**: Dashboard overview of repositories, showing snapshot counts and latest snapshot dates.
19. **[umounter](commands/umounter)**: Elegantly kill background mounter processes and safely unmount the repository.
20. **[unlocker](commands/unlocker)**: Delete the temporary `.lock` file created by the script if it got stuck.
21. **[upgrade](commands/upgrade)**: Upgrade your restic repository to the newer v2 repository format.

### Rescript Global Flags

Rescript features several global flags that can be mixed naturally with its own commands or native `restic` commands.

**[View all Global Flags details here](global-flags)**

1. **`-D, --debug`**: Enable trace debugging (`set -xv`) for the script.
2. **`-E, --email`**: force to send email with output.
3. **`-h, --help`**: display help for a specific command.
4. **`-L, --log`**: Create a logfile for this specific manual run.
5. **`-M, --metadata`**: Display execution context metadata.
6. **`-Q, --quiet`**: silence output. If you use `--log` it will still log the output.
8. **`-T, --timer`**: display output with date, time and duration at the end of execution.

Make use of `rescript` global flags with `restic` commands normally:
```
rescript [repo_name] [restic_command] -L -Q [restic_flags] ...
```
