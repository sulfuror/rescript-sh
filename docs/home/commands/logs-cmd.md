---
title: logs
---

The `logs` command allows you to view or manage the log files generated by rescript (if `LOGGING="yes"` is set in your configuration).

### Usage
```bash
rescript [repo_name] logs [options]
```

### Flags
- `-W, --view [logfile]`: Display the full output of a selected log file in the terminal.
- `-R, --remove [logfile]`: Delete a specific log file. (Use `all` instead of a filename to delete all logs for this repository).

### Examples

**List all available log files for a repository:**
```bash
rescript my_repo logs
```
*Output:*
```text
Available log files for my_repo:
my_repo-2026-07-10-100000.log
my_repo-2026-07-11-100000.log
```

**View the contents of a specific log file:**
```bash
rescript my_repo logs --view my_repo-2026-07-10-100000.log
```
*This will print the full execution trace and Restic output captured during that specific run.*

**Delete all logs for a repository:**
```bash
rescript my_repo logs --remove all
```
